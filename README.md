SkyCast is a simple and responsive weather web application that allows users to search for any South African city and view real-time weather information.

Features: 
 - Search weather by city name
 - Displays temperature in Celsius
 - Shows weather conditions (e.g., clear, cloudy, rain)
 - Includes additional details like:
 - Feels-like temperature
 - Humidity
 - Wind speed
 - Clean and responsive UI using Bootstrap

Tech Stack: 
 - Node.js
 - Express.js
 - EJS (Embedded JavaScript Templates)
 - Axios
 - Bootstrap 5
 - OpenWeatherMap API
